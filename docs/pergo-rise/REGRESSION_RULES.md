# Regression Rules

- Do not change PLMR 2D geometry/runtime rules inside P3DV.
- Do not use Freedom geometry or Freedom derived data for Pergo Rise.
- Do not scale the complete GLB on X/Y/Z.
- Do not scale GLB profile cross-sections.
- Do not rebuild iframe/WebGL context on Pergo Rise measurement changes.
- Preserve viewer session, camera position, target and zoom during live project updates.
- Do not add animation to `STATIC_OPEN_REAR_STACKED`.
- Do not promote LOW/MEDIUM mapping confidence without authoritative evidence.
- Do not mark physical AR PASS without a supported real device/HTTPS session.
- Run all legacy Node tests, headed WebGL acceptance, PDF render and ZIP re-extract tests before a new canonical package.
